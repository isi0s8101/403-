# Sillons d'Empire 0.17.0 — Guide des gestes et des commandes

Tout se joue **au pouce, en paysage**. La place des boutons et les gestes sont **les mêmes à tous les âges** : seul le style change.

## L'écran

| Où | Quoi |
|---|---|
| **Haut** | Ressources (toucher = priorité de récolte ; revenus « +N/m »), population (toucher = ouvriers inactifs, ou une maison si la population est pleine), âge (devient « Monument ! » quand un monument est possible : un toucher pour le placer), Conseil, Civilisation |
| **Sous la barre du haut** | File d'alertes : attaque, pénurie, recherche ou monument fini, âge, héros tombé, pouvoir prêt. Bouton **Voir** = la caméra y va |
| **Bord gauche** | 6 **groupes de contrôle** |
| **Bas gauche** | **Inactifs**, **Armée**, **Héros**, **Former**, **＋** (sélection additive), puis **Bâtir**, **Choisir**, **⌂** |
| **Bas centre** | Ce qui est sélectionné : un portrait par type avec effectif et santé |
| **Bas droite** | **Carte de commandes** (elle change selon la sélection) avec le bouton **Enchaîner** |
| **Droite** | Mini-carte (toucher = sauter, glisser = défiler ; points rouges = attaques), menu, **pause active** (❚❚ / ▶), vitesse, héros et pouvoirs, Armées |

## Sélectionner

- **Toucher une unité** : son escouade. **Deuxième toucher lent** : cette unité seule. **Appui long** sur une unité : elle seule.
- **Double toucher rapide** sur une unité : **toutes les unités du même type visibles à l'écran**.
- **Rectangle** sans bouton : **glisser en partant d'une de vos unités**, ou **appui long au sol puis glisser**. Le bouton « Choisir » marche toujours.
- **＋** : chaque toucher ajoute ou retire une unité ; le rectangle ajoute.
- **Portraits du bas** : toucher = ne garder que ce type ; appui long = le retirer.
- **Inactifs** : un toucher sélectionne tous les ouvriers inactifs ; chaque toucher suivant centre sur le prochain.
- **Armée** : toute votre armée de la carte. **Héros** : vos héros présents.

## Groupes de contrôle (bord gauche)

- **Appui long** sur un numéro : il retient la sélection.
- **Toucher** : la rappelle. **Double toucher** : la rappelle et centre la caméra.
- Le chiffre en haut à droite = unités encore en vie ; la barre = leur santé.
- Les groupes restent quand vous passez au globe, à l'orbite, au système ou à la galaxie, et sont enregistrés avec votre sauvegarde.

## Donner des ordres

- **Toucher le sol** : marcher. **Toucher un ennemi** : l'attaquer.
- Ouvriers sélectionnés : **toucher un arbre, des baies, du minerai ou une ferme** = récolter ici ; **toucher un chantier** = le bâtir ; **toucher un bâtiment abîmé** = le réparer.
- **Carte de commandes** (troupes) : Marcher, **Assaut** (avance et combat en route), **Arrêt**, **Tenir** (ne poursuit pas), **Patrouille**, **Repli** (rentre à la base sans combattre), **Garnison** (entrer dans un bâtiment : protégé, tire depuis l'intérieur). **Plus ›** : **Formation** (bloc, ligne, colonne, carré, dispersée — tournée vers la destination), **Posture** (agressive, défensive, tenir, passive), **Cible** prioritaire (tireurs, cavaliers, siège…), **Suivre**, **Explorer** (éclaireurs), **Rendre** (fin du contrôle direct).
- **Carte de commandes** (ouvriers) : Bâtir, Réparer, Récolter, Dépôt, **Auto** (retour à l'économie automatique), Arrêt, Garnison.
- **Appui long au sol** : menu d'ordres circulaire (Marcher, Assaut, Arrêt, Tenir, Repli, Garnison, Cibler…).
- Chaque ordre laisse une marque colorée au sol. Un ordre refusé affiche **sa raison près du doigt** et ne change rien.

## Enchaîner plusieurs ordres (A → B → C…)

1. Touchez **Enchaîner** (il reste actif) — ou **maintenez-le** au pouce gauche pendant que vous touchez la carte.
2. Chaque ordre **s'ajoute à la suite** : touchez A, puis B, puis C. Le bouton affiche « Enchaîner · 3/16 ».
3. Sans Enchaîner, un ordre **remplace** la file.

- Les étapes s'affichent **au sol** : numéros 1, 2, 3… reliés par des pointillés de la couleur de l'ordre ; l'étape en cours est plus grande ; « ↻ » si la file boucle.
- **Toucher un numéro** : **Déplacer**, **Supprimer**, **Insérer avant**.
- **↶** annule la dernière étape, **✕** vide la file, **↻** fait boucler (patrouille sur plusieurs points).
- Étapes possibles : marcher, assaut, attaquer une cible, attendre, tenir une zone, escorter, suivre, explorer, **bâtir**, **récolter**, **déposer**, **réparer**, garnison, rendre à l'armée.
- **Ouvriers** : sélectionnez-les, touchez Enchaîner, puis posez des bâtiments : chaque pose devient un chantier de leur file (« bâtir A puis B puis C »).
- Un groupe garde sa formation et **attend ses retardataires** à chaque point. Une étape devenue impossible (destination inaccessible, cible morte, chantier détruit, ressource épuisée) est **sautée** avec une alerte.
- Les ordres se donnent aussi **pendant la pause active** (❚❚).
- Limites : 16 étapes, 128 unités par ordre.

## Construire

- **Bâtir** puis choisir le bâtiment : le fantôme est vert (possible) ou rouge, **avec la raison écrite au-dessus**.
- **Ligne** : glissez le doigt pour aligner murs ou maisons, puis **Valider**.
- **Plusieurs** : le mode reste actif ; un toucher sur un emplacement valide pose aussitôt.

## Produire

- Dans la fiche d'un bâtiment : **×1 / ×5** (cinq d'un coup), **appui maintenu** sur une carte = formation en continu, **Répéter** (la file se relance seule tant que population et ressources le permettent).
- La **file** est visible : toucher un élément l'annule et le rembourse. Le nombre en file s'affiche sur la carte.
- **Former** (bas gauche) : former une unité depuis n'importe où, dans le producteur le moins chargé.
- Centre : **Ouvriers → ressource** puis toucher un gisement : les nouveaux ouvriers vont le récolter directement.
- **Démolir** (deux touchers pour confirmer) et **Sortir la garnison**.

## Héros et pouvoirs (colonne droite)

- **Héros** : portrait, vie, état (en service, en formation, tombé — rappel dans N s). Toucher = sélectionner ; double toucher = centrer. Leur aura est un cercle léger au sol.
- **Pouvoirs** : points de commandement, anneau de recharge. Toucher un pouvoir = viser : **le rayon s'affiche au sol** ; touchez (ou glissez puis relâchez) pour lancer. **Retour** annule sans rien dépenser.

## Style de l'interface

- L'interface prend le style de **l'âge de votre civilisation** : pierre et bois (I), parchemin et bronze (II), fer forgé (III), laiton (IV), marbre et or (V), acier peint (VI), console radar (VII), écran plat (VIII), verre et lumière (IX), application « next-gen » irisée (X).
- Au passage d'âge, une courte **cérémonie** (1 à 2 s) montre le nouveau style ; le jeu continue dessous ; un toucher la passe.
- Menu pause : **Thème** (suit l'âge, ou un âge fixe), **Sons d'interface**, **Vibrations**, **Main gauche** (miroir des barres), **Réduire les animations**, **Échelle de l'interface** (85 à 130 %), **Afficher les portées**. Ces réglages sont enregistrés.

## Bouton Retour d'Android

Il ferme dans l'ordre : panneaux, menu circulaire, cérémonie, bulle d'étape, mode en cours (pose, visée…), Enchaîner, production globale, sélection additive, puis le menu pause.
