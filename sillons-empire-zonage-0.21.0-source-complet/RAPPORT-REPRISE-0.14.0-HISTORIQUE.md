# Reprise et intégration 0.14.0

Base : ZIP complet 0.13.5, SHA-256 `3680e6a25e54e8b6b518648ebefb7eba72ddaaba2e039f4c147bb90fe02a99ba`.

Le projet contient les nouveaux modules dans `sillons/evolution`. Dix fichiers historiques de simulation ont été modifiés pour les dimensions, factions, ordres, stocks et enveloppes de sauvegarde ; les autres fichiers du socle sont comparés à la référence conservée. L'ancienne affirmation « simulation byte pour byte identique à 0.13.2 » ne s'applique plus : la non-régression est vérifiée par les scénarios historiques.

La comparaison complète des fichiers et les empreintes sont livrées à la racine. Les modèles, textures et paquets natifs de la refonte 0.13.5 sont conservés. Aucun GLB n'est placé dans le projet Godot jouable. Les documents et preuves de livraison 0.13.5 ont une copie historique.
