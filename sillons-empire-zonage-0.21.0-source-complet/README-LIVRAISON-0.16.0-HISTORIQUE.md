# Sillons d'Empire 0.16.0 — Évolution de la civilisation (candidate)

Base : 0.15.1 R2 (auditée : voir [AUDIT-0.15.1-R2.md](AUDIT-0.15.1-R2.md)). Le projet s'ouvre avec `sillons/project.godot` dans **Godot 4.7.2**.
Lancer **Nouvelle campagne · deux systèmes**, puis le bouton **Civilisation** en haut de l'écran.

- **Voies** : à l'âge II, V et VIII, choisir une voie marchande, militaire ou savante — bonus permanent et une unité spéciale.
- **Monuments d'âge** : on passe à l'âge suivant en bâtissant un des deux monuments proposés ; son bonus dure tant qu'il est debout.
- **Forge et améliorations** : onze lignes à trois niveaux (armes, armures, balistique, blindage, outils, charrues, bâtisseurs…).
- **Héros** : un par époque, unique, aura sur les troupes proches, rappel après sa chute.
- **Pouvoirs de commandement** : points gagnés en détruisant des forces ennemies ; ravitaillement, éclaireurs, cri de ralliement, renforts, bombardement, bouclier.
- L'IA utilise les mêmes règles et les mêmes commandes.

Détails : [sillons/README-CIVILISATION-0.16.0.md](sillons/README-CIVILISATION-0.16.0.md). Validation : `sillons/game-studio/VALIDATION-CIVILISATION-0.16.0.md`.
Les 52 scénarios Godot passent sous Linux (sans rendu graphique). **Aucun APK n'est fourni avec cette version ; Android et Galaxy S25 Ultra : NOT_RUN.**
Les escarmouches historiques, les scénarios de laboratoire et les sauvegardes 0.15 conservent leurs règles.
