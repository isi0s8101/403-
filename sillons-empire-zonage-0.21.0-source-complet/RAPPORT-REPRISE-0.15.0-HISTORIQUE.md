# Reprise 0.15.0 depuis la livraison complète 0.14.0

La livraison reprend toutes les sources, cadrages, modèles, textures et preuves de la 0.14.0, puis ajoute une interface locale photographiée, un accueil 3D et un théâtre orbital persistant. L’ancienne archive est conservée.

Le détail fonctionnel est dans `README-INTERFACE-0.15.0.md`. Les résultats réels, les journaux, les benchmarks et les captures sont dans `sillons/game-studio/preuves/interface-orbite-0.15.0/`. La comparaison de fichiers avec la 0.14 et les manifestes SHA-256 sont générés pendant l’assemblage ; ils permettent de contrôler les sources conservées et les modifications.

L’UI a été inspectée dans le moteur à 1280 × 600. Les captures incluent des missions réellement émises par la fixture de contrôle et présentes dans les inventaires de campagne.

Cette archive contient les sources, pas une installation sur le téléphone. L’Android réel et Vulkan ne sont pas validés ; une campagne complète et les combats maximaux demandent encore une qualification dédiée.
