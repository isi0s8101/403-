# Sillons d’Empire 0.15.1 R2 — APK de recette

Lancer **Sillons d’Empire Test R2**. Les trois scénarios de mesure sont accessibles dans **Laboratoire et scénarios → Performances Android**.

L’APK ARM64 est fourni séparément du ZIP source. Le guide est [README-ANDROID-0.15.1-R2.md](README-ANDROID-0.15.1-R2.md). Le projet source s’ouvre avec `sillons/project.godot` dans Godot 4.7.2.

50 scénarios passent sous Linux ; les ressources compilées de l’APK sont également vérifiées. La signature, le manifeste et l’alignement sont contrôlés. Le test sur téléphone reste à effectuer. La simulation et les ressources de la base 0.15.0 sont conservées.
