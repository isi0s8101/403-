# Sources 3D conservées hors du projet jouable

Ce dossier est le dossier `sillons/assets_3d/` complet de la version 0.13.3, déplacé sans modifier ses fichiers. Il comprend les GLB, textures, aperçus et références. Les chemins relatifs du catalogue restent inchangés.

Ouvrir `../sillons/project.godot`, pas ce dossier. Ne pas le déplacer dans `sillons/` : Godot Android réimporterait les milliers de modèles. Le jeu utilise le paquet prêt à charger `../sillons/data/assets_3d.pck`. Outil de préparation sur ordinateur : `../sillons/tools/prepare-native-assets.py`.
